# 전체 연결 재점검 및 STT 설정 안내

> 이후 변경: [API 없는 로컬 실행 구성](../desktop/offline-runtime-2026-10-19.md)에서 기본 다국어 STT 모델, Windows FFmpeg/ffprobe, 고급 DPAPI 라이브러리 내장을 완료했습니다. 아래의 별도 STT 모델 준비 설명은 사용자 지정 모델을 쓸 때의 참고이며, 최신 Windows 설치 파일의 기본 사용에는 필요하지 않습니다.

PR #26의 6개 기능 후속 구현에 대한 두 번째 점검이다. main 병합은 담당자가 수행한다.

## STT의 로컬 모델이란

STT(Speech-to-Text)는 녹음의 음성을 글자로 바꾸는 기능이다. 실행 프로그램인 Faster Whisper와 학습된 모델 파일은 서로 별개다. 최신 Windows 설치 파일은 두 가지를 모두 포함하며, 기본 Whisper base 다국어 모델을 자동 사용한다. 인터넷 AI 서비스의 API 키는 필요하지 않으며 녹음을 외부로 전송하지 않는다. 아래 절차는 기본 모델 대신 **사용자 지정 모델**을 선택할 때만 해당한다.

1. Faster Whisper/CTranslate2용 모델의 전체 폴더를 준비한다. `model.bin`, `config.json`, `tokenizer.json`, `vocabulary.*` 파일이 필요하다. 원본 Whisper의 `.pt` 파일 하나로는 실행할 수 없다.
2. 한국어를 인식하려면 다국어 모델을 사용한다. `.en` 모델은 영어 전용이다. 공식 배포 예시는 [Systran/faster-whisper-small](https://huggingface.co/Systran/faster-whisper-small)이다.
3. **설정 → 로컬 OCR·음성 인식 → Faster Whisper → 음성 모델 선택**에서 폴더를 선택하고 저장한다. 화면에 저장된 분석기·모델의 준비 상태가 표시된다.
4. 증거 파일을 등록·인덱싱한 후 음성 파일을 선택한다. **복구·카빙·OCR·ADS → 한국어 음성 또는 음성 언어 자동 → 선택 파일 음성 인식**을 누른다.
5. 작업 완료 후 **자동 추출 후보**에서 텍스트와 시간 구간을 검토한다. 자동 인식 결과는 관찰 사실로 자동 승격되지 않는다.

소스 개발 환경에서 모델을 준비하는 예시(PowerShell, machine-extraction 의존성 설치 후):

```powershell
$env:HF_HUB_DISABLE_TELEMETRY = '1'
uv run --no-sync python -c "from huggingface_hub import snapshot_download; snapshot_download('Systran/faster-whisper-small', local_dir='C:/APEX/Models/whisper-small')"
```

이 명령은 공개 모델 다운로드에만 네트워크를 사용한다. 앱에서 분석할 때는 로컬 파일만 불러온다. 모델 가중치의 실제 호환성·추론 성공은 실행 시 확인되므로 '파일 준비됨'이 모든 모델의 정확도를 보장하는 것은 아니다. 대체 분석기 `whisper.cpp`는 모델 파일과 PATH의 `whisper-cli` 실행 파일을 별도로 준비해야 한다.

## 발견하여 수정한 항목

| 구분 | 기존 문제 | 수정 및 검증 |
| --- | --- | --- |
| STT 설정 | 존재하는 폴더면 불완전한 모델도 저장됨; 분석기 변경 시 이전 모델이 남음 | 필수 파일·빈 파일·JSON 구성을 저장 전에 검사하고 오류 시 이전 설정 보존. 분석기 변경 시 모델 선택 초기화. 설정 해제·환경변수 관리 상태·한국어 안내 추가 |
| STT 시간 | whisper.cpp의 실제 `offsets.from/to`를 읽지 못함; 정수 초가 ms로 오인됨 | 실제 JSON의 ms, 초 단위 start/end, 10 ms tick의 t0/t1을 구분. 0 ms도 보존 |
| STT 언어 | 자동 선택을 CLI에 전달하지 않음; 영어 모델에서 한국어 요청이 영어로 대체됨 | `-l auto` 전달, 실제 감지 언어 보존, 영어 전용 모델의 한국어 요청 명시적 오류 |
| STT 출처·성능 | whisper.cpp 결과에 원본 SHA-256·모델 식별 누락; Faster Whisper가 구간마다 원본 재해싱 | 두 분석기에 출처 연결. 음성 파일 해시는 실행당 한 번 계산 |
| 한국어 OCR | 자동 선택이 영어만 설치된 Tesseract를 우선하여 한국어 실행 실패 | 요청 언어가 없으면 사용 가능한 RapidOCR 한국어 모델로 전환. 사용자가 명시적으로 Tesseract를 선택한 경우는 유지 |
| AI 발췌문 | 따옴표가 있는 JSON 비밀번호, Bearer/Basic 인증값, 잘린 문자열 일부를 가리지 못함 | 해당 패턴과 이스케이프 따옴표를 처리. 안전한 password_hash 필드는 유지. 본문 검토와 사건 정책은 계속 필수 |
| 결과 보존 | 앱 재시작 후 복구·ADS 결과 경로, 카빙 manifest·next_offset, OCR/STT 후보 참조가 작업 화면에서 사라짐 | 필요한 결과 메타데이터를 작업 기록에 보존. 증거 본문과 카빙 후보 전체를 작업 기록에 복제하지 않음 |
| 재시작 복구 | UTF-8이 아닌 작업 기록이나 잘못된 task_id 자료형이 시작을 중단시킬 수 있음; 중단 작업의 취소 버튼 잔류 | 손상 기록 보존 후 정상 시작. 재시작 시 실제 취소 토큰 없는 버튼 제거 |
| 빈 삭제 파일 | 크기 0인 삭제 파일을 읽기 실패로 취급 | TSK가 식별한 0 byte 삭제 파일을 빈 파생 파일로 복구하고 해시·보관 이력 기록 |
| 로컬 실행 통신 | 선택적 ONNX Runtime의 기본 텔레메트리로 분석과 무관한 외부 연결 발생 가능 | Core 초기화에서 ORT/Hugging Face 텔레메트리 비활성화. ONNX 초기화 전 환경변수와 구형 런타임 API 모두 적용 |
| UI 계약 | 새 작업 이름과 일부 오류 설명이 불충분하거나 이전 미지원 안내가 남음 | 새 작업명·STT 오류·본문 추출 오류를 한국어로 표시. 이미지 내부 픽셀 분석에 대한 오래된 미지원 문구 제거 |

## 점검 범위와 근거

| 범위 | 확인한 경로 |
| --- | --- |
| 앱·로컬 API | Electron allowlist와 Python 요청 모델 **44개 작업** 일치, 사건/증거 선택·페이지 이동·비동기 응답 무효화, 작업 완료·취소·재시작, 네이티브 경로 선택 권한 |
| 이미지·파일 엔진 | RAW/E01/VHD/VHDX → 파일시스템 → 실제 내용·Hex·미디어, 삭제 파일·ADS·카빙, 원본 충돌 방지와 해시·보관 이력 |
| 분석·검색 | 기존 아티팩트·검색 인덱스·타임라인·OCR/STT 후보 저장·검토, 원본 node/revision 연결 |
| AI | API 미설정, 발췌문 준비·가림·검토 fingerprint·최종 정책, 구조/본문 결과 분리, 실제 HTTP 직전 정책 평가 |
| 보고서 | 초안·근거 인용·검토·승인·내보내기·stale 상태에 대한 기존 통합 테스트 |
| 기존 인증·MCP | 로그인, 토큰 갱신·재사용 차단, 비활성 계정, 세션/사건 역할, 일회 승인, MCP 계약·stdio 실행 테스트 |

전체 테스트 통과는 모든 손상 증거와 모든 파일 형식의 지원을 의미하지 않는다. 차등 VHD/VHDX 부모 체인, 암호화 볼륨, 조각난 파일 자동 재조립, 실제 원격 AI API 호출 및 한국어 음성 정확도 벤치마크는 여전히 별도 범위다. 기본 STT 추론 제한은 120초이며 네이티브 추론의 취소/시간제한은 실행 스레드를 즉시 강제 종료하지 않는다. 긴 녹음과 큰 모델은 이 제한에 도달할 수 있다. 지원 범위 상세는 [기능별 완료 문서](completed-connections-2026-10-19.md)를 따른다.

## 검증

- 수정 후 전체 Python 테스트와 0 byte 삭제 파일 회귀 검사 통과. 정확한 최종 실행 수 및 CI는 PR 본문에 기록한다.
- 프론트 **65개** 테스트, CSP 검사, TypeScript/Vite/Electron 빌드 통과.
- Ruff 및 mypy strict **180개 소스** 통과. 설계·Schema 검사 및 Bandit 분류 검사 통과.
- 실제 Faster Whisper 로컬 tiny.en 모델과 공개 음성 샘플에서 텍스트 및 0–8000 / 8000–11000 ms 구간 재검증. 한국어 모델의 정확도를 시험한 것으로 간주하지 않는다.
- 로컬 release gate의 선택적 AJV CLI 검사는 해당 CLI 미설치로 실행되지 않았으며, 프론트 빌드의 실제 AJV 계약 생성·검증은 통과했다. 이를 모든 선택적 검사 통과로 표시하지 않는다.
- 전체 테스트 첫 실행은 ONNX 텔레메트리 외부 연결에 대한 자동 승인 검토로 차단되었다. 원격 접속 허용 대신 런타임 텔레메트리를 끄고 로컬 모델로 다시 실행했다.

STT 출력 단위는 [whisper.cpp 공식 CLI 소스](https://github.com/ggml-org/whisper.cpp/blob/master/examples/cli/cli.cpp), 모델 구성은 [Faster Whisper 공식 문서](https://github.com/SYSTRAN/faster-whisper), 텔레메트리 설정은 [ONNX Runtime 공식 Privacy 문서](https://github.com/microsoft/onnxruntime/blob/main/docs/Privacy.md)를 대조했다.
