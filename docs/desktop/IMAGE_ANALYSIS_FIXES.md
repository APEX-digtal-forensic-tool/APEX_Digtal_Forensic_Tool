# 이미지 분석 및 실제 앱 검증 후속 수정

2026-09-16 실제 macOS 앱에서 PNG 스테가노그래피 문제를 분석하며 확인한 7건의 수정 내역이다. 기능 구현과 실제 앱 재검증 완료 여부를 구분한다.

## 변경 내용

| 항목 | 반영한 변경 |
|---|---|
| F-01 이미지 표시 없음 | 파일/미디어 검사기에 이미지 분석 창 추가. 원본 픽셀에서 생성한 PNG 미리보기, 확대율, 표시 크기, RGB 및 개별 채널 표시 제공 |
| F-02 비트 분석 없음 | bit 0–7 평면 표시, 중복 없는 RGBA 채널 순서 지정, MSB/LSB 바이트 조합, 시작 픽셀 및 추출 길이 지정. 텍스트/Hex와 출처·해시·분석 조건을 표시하고 JSON 저장 |
| F-03 ZIP이 RAW로 등록됨 | 압축 확장자와 ZIP·7z·RAR·gzip 시그니처를 확인해 등록 전에 차단하고, 원본을 보관한 뒤 별도 폴더에 압축 해제하여 가져오도록 안내 |
| F-04 주요 이미지 필드 누락 | 기본 정보에 포맷·MIME·가로·세로 추가. 상세 정보에 이미지 메타데이터·EXIF·썸네일 상태 제공 |
| F-05 관련도 점수를 순위로 표시 | 검색 순번과 BM25 관련도 점수 분리. 점수 정밀도 및 낮을수록 관련도가 높다는 설명 추가 |
| F-06 원본 잔여 여부 오표시 | `truncated`를 요청 범위/미리보기 잘림으로 표시하고, 반환 오프셋·길이·전체 길이로 남은 바이트 별도 계산 |
| F-07 한국어·보고서 HTML 마감 | 검토/승인/내보내기 상태 한국어 표시. 보고서 고정 제목을 locale에 따라 표시하고 중복 `<p>` 래핑 제거 |

## 이미지 분석 경계

- 프런트는 `media.inspect` 작업으로 사건 ID와 등록된 파일/아티팩트 ID를 전달한다. 원본 경로를 임의로 전달하지 않는다.
- 픽셀 읽기와 비트 추출은 Core의 `ImageInspectionService`에서 수행한다. 사례 범위·파일 유형·링크·원본 해시 변경·입력 범위를 확인한다.
- PNG/JPEG/GIF/TIFF/BMP/WebP의 첫 프레임을 8비트 RGBA로 변환한다. 저장된 픽셀 순서를 유지하며 EXIF 회전은 적용하지 않는다. 16비트 채널의 원래 비트 깊이 그대로 추출하는 기능은 포함하지 않는다.
- 파일 최대 64 MiB, 이미지 최대 2,500만 픽셀, 동시 디코딩 최대 2건, 추출 최대 65,536바이트다. 미리보기는 선택한 크기로 축소될 수 있지만 추출은 축소된 미리보기를 사용하지 않는다.
- 추출 JSON은 앱 데이터의 `local/exports/image-analysis/<결과 ID>.json`에 저장된다. 원본 바이트를 변경하지 않으며 외부 서비스로 전송하지 않는다.
- 디스크 이미지 내부의 파일 픽셀 분석, 자동 압축 해제, 모든 스테가노그래피 기법의 자동 탐지는 이번 범위에 포함하지 않는다.

## 검증 상태

사용자 요청으로 추가 테스트와 실제 앱 재검증을 중단했다. 아래는 중단 이전에 수행한 결과이며 최종 커밋의 전체 검증 완료를 뜻하지 않는다.

- 프런트 회귀 테스트 58개 통과. 엔진 호출 연결, 실행한 추출 조건 보존, 선택 변경 후 오래된 응답 무시, 원본 잔여 바이트 표시를 포함한다.
- 관련 Python 테스트 55개 통과, 1개 건너뜀. 픽셀 추출·출처·해시·상세 투영, 사건 범위, 원본 변경, 링크·디코딩·입력 한도, ZIP 입력 안내, HTML 한국어/escaping을 포함한다.
- 확장 Python 실행은 492개 통과, 21개 건너뜀, 8개 실패였다. 로컬 서버 권한 문제에 해당하는 파일들은 환경을 맞춘 재실행에서 7개 통과했다. 합성 벤치마크의 macOS 임시 경로 문제는 실제 경로를 지정한 재실행에서 1개 통과했다.
- 남은 Prefetch MAM 테스트 실패는 선택 의존성 `dissect.util` 미설치 상태에서 발생했다. 이 환경에서 전체 Python 테스트 통과로 기록하지 않는다.
- 중단 이전 프런트 타입 검사/빌드, Python 소스 타입 검사 및 관련 Ruff 검사, macOS arm64 Python 런타임 빌드는 통과했다.
- 최신 Electron 패키지 생성은 GitHub 다운로드 연결 실패로 완료되지 않았다. 수정한 앱에서 실제 문제 파일을 다시 열어 이미지·플래그·채널/비트 평면을 확인하는 네이티브 재검증은 미수행이다.
- 중단 후 경로 범위 검사 보완, 검색 순번 라벨과 문서를 정리했다. 이 최종 변경은 요청에 따라 추가 테스트하지 않았다.

## 재개 시 확인할 항목

- [ ] 최신 macOS 앱 패키지 생성 및 실제 앱 실행
- [ ] 동일 증거를 사용한 이미지 표시·확대·채널·비트 평면·텍스트/Hex 추출 확인
- [ ] ZIP 선택 시 안내와 미등록 상태, 상세 필드, 검색 순번/점수, 원본 잔여 바이트 확인
- [ ] 한국어 검토 상태 및 새 HTML 내보내기 결과 확인
- [ ] 선택 의존성 설치 환경에서 Prefetch MAM 및 전체 회귀 테스트
- [ ] Windows 및 Intel Mac에서 빌드·실행 확인

로컬 문제 파일·플래그·원본 경로가 담긴 상세 검증 산출물은 버전 관리에서 제외한다. 이 문서는 기존 가이드 전체의 기능 완료를 선언하지 않는다.
