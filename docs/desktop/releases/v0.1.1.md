# APEX 0.1.1 Preview

FTK Imager의 증거 탐색 구조를 참고해 APEX 데스크톱 작업 화면을 개선한 프리릴리즈입니다. Electron 앱과 로컬 Python 분석 엔진을 함께 포함합니다.

## 변경 사항

- 증거 트리·속성·파일 목록·내용 뷰어를 동시에 보는 네 영역의 다크 테마 작업 화면
- 일반 파일까지 표시하는 증거 트리와 파일 아이콘, 선택한 파일의 부모 폴더·속성·내용 연동
- Preview / Text / Hex / 메타데이터 전환, 주소·바이트·ASCII 열, 최대 4 KiB 단위 원본 읽기 및 오프셋 이동
- 상단 작업 도구 모음과 가로 분석 탭, 폴더 경로 이동, 포인터·키보드 패널 크기 조절 및 초기화
- 증거 전환과 지연 응답 처리 개선, 합성 데모와 실제 엔진 상태 표시 구분
- 제공된 APEX 로고 오른쪽이 잘리던 표시 오류 수정

## 다운로드

| 환경 | 설치 파일 | 별도 압축 파일 |
| --- | --- | --- |
| Windows x64 | `APEX-0.1.1-Windows-x64.exe` | — |
| macOS Apple Silicon | `APEX-0.1.1-macOS-arm64.dmg` | `APEX-0.1.1-macOS-arm64.zip` |
| macOS Intel | `APEX-0.1.1-macOS-x64.dmg` | `APEX-0.1.1-macOS-x64.zip` |

별도 Python·Node.js 설치는 필요하지 않습니다. 개발 서버의 합성 데모는 설치 파일에서 활성화되지 않습니다. 자동 업데이트는 제공하지 않으므로 새 설치 파일로 직접 업데이트하세요.

**배포 인증서 서명 및 Apple 공증을 받지 않은 프리뷰입니다.** Windows SmartScreen이나 macOS Gatekeeper의 확인 또는 실행 제한이 나타날 수 있습니다.

## 검증과 출처

- 배포 소스: [PR #24](https://github.com/APEX-digtal-forensic-tool/APEX_Digtal_Forensic_Tool/pull/24)의 `099871d3da84908550b66d9d78beb70bfdc19e2d`. 이 프리뷰는 해당 브랜치 커밋을 기준으로 배포합니다.
- [Windows x64 · macOS arm64 · macOS x64 CI](https://github.com/APEX-digtal-forensic-tool/APEX_Digtal_Forensic_Tool/actions/runs/35165188139): 테스트, 타입·린트 검사, 엔진 런타임 확인, 설치 파일 생성 통과
- [MCP·백엔드·보안 및 패키지 CI](https://github.com/APEX-digtal-forensic-tool/APEX_Digtal_Forensic_Tool/actions/runs/35165188158): 통과
- CI가 빌드한 PR merge 커밋과 배포 커밋의 Git tree가 동일함을 확인하고, 성공한 실행의 고정된 아티팩트 ID와 SHA-256을 검증한 뒤 게시합니다.

`SHA256SUMS.txt`는 첨부 파일의 SHA-256을, `build-provenance.json`은 배포 소스·빌드 커밋·CI·원본 아티팩트의 출처를 제공합니다. 체크섬은 코드 서명을 대신하지 않습니다.

## 확인 범위와 제한

- 로컬 프로덕션 빌드·타입 검사와 브라우저의 합성 데모 탐색을 확인했습니다. 자동 회귀 검증과 네이티브 설치 파일 빌드는 위 원격 CI 결과를 기준으로 합니다.
- 실제 증거·대용량 이미지·각 OS의 설치 후 전체 시나리오를 수동 검증한 정식판은 아닙니다. 이미지 미리보기와 디스크 이미지 내부 파일의 지원 범위는 기존 제한을 따릅니다.
- 이번 변경은 작업 화면과 파일 탐색 개선입니다. 디스크 획득·메모리 수집·이미지 마운트 기능을 추가하지 않습니다.
- 백엔드 서비스나 MCP 서버가 함께 배포되거나 데스크톱 AI 기능이 새로 연동되는 릴리즈는 아닙니다. 인증 서버·MCP는 별도 실행 및 설정이 필요하고 일부 AI·OCR/STT·복구 기능은 미구현 또는 별도 의존성을 요구합니다.
- 웹 번들의 500 kB 경고가 남아 있으며 코드 분할은 후속 개선 대상입니다.
