# APEX 0.1.2 Preview

OpenAI 호환 AI 제공자(Moonshot Kimi K3로 실제 호출 확인)를 MCP와 데스크톱 AI 도우미에 연결해, 아티팩트 대상 AI 분석 한 사이클이 끝까지 동작하도록 수정한 프리릴리즈입니다. Electron 앱과 로컬 Python 분석 엔진을 함께 포함합니다.

## 변경 사항

- 아티팩트 선택 시 Core가 직접 만든 원본 파일 인용을 범위 밖으로 거부하던 인용 검증 오류 수정(`AI_CITATION_SCOPE_MISMATCH`)
- 구조 정보만 전송한 요약에서 제공자가 인용을 비워 반환하면 스냅샷의 로컬 인용을 연결하고 `AI_LOCAL_CITATIONS_ATTACHED` 경고로 표시
- 제공자 응답의 Markdown 코드 블록·앞뒤 문장을 제거해 JSON을 복구하고, 문자열 경고를 경고 객체로 정규화
- 추론 모델의 긴 응답 시간을 고려해 데스크톱 AI 분석 요청 제한 시간을 300초로 확대
- 개발용 도구: `tools/verify_mcp_ai_cycle.py`(MCP stdio로 스냅샷→요청→실행 검증), `tools/run_gui_ai.ps1`(AI 제공자 설정과 함께 개발 GUI 실행)

## 다운로드

| 환경 | 설치 파일 | 별도 압축 파일 |
| --- | --- | --- |
| Windows x64 | `APEX-0.1.2-Windows-x64.exe` | — |
| macOS Apple Silicon | `APEX-0.1.2-macOS-arm64.dmg` | `APEX-0.1.2-macOS-arm64.zip` |
| macOS Intel | `APEX-0.1.2-macOS-x64.dmg` | `APEX-0.1.2-macOS-x64.zip` |

별도 Python·Node.js 설치는 필요하지 않습니다. 개발 서버의 합성 데모는 설치 파일에서 활성화되지 않습니다. 자동 업데이트는 제공하지 않으므로 새 설치 파일로 직접 업데이트하세요.

**배포 인증서 서명 및 Apple 공증을 받지 않은 프리뷰입니다.** Windows SmartScreen이나 macOS Gatekeeper의 확인 또는 실행 제한이 나타날 수 있습니다.

## AI 제공자 설정

AI 기능은 선택 사항입니다. 키는 설치 파일·저장소에 포함되지 않으며 앱 실행 환경의 환경변수로 제공합니다.

```powershell
$env:APEX_DESKTOP_AI_CONFIG = '{"provider_id":"moonshot-kimi","base_url":"https://api.moonshot.ai/v1","model_id":"kimi-k3","api_key_env":"APEX_AI_API_KEY","temperature":1.0,"max_output":16384,"timeout":240}'
$env:APEX_AI_API_KEY = '실제 키'
```

- `kimi-k3`는 `temperature=1`만 허용합니다. 다른 OpenAI 호환 제공자는 해당 모델의 허용 값을 사용하세요.
- 사건별 AI 데이터 정책에서 AI 사용·외부 AI 사용을 허용하고 로컬 전용 제한을 해제해야 전송됩니다. 앱은 기본 정책을 자동으로 바꾸지 않습니다.

## 확인 범위와 제한

- 데스크톱의 "구조 정보 요약"은 안전한 투영(개수·상태 등)만 전송하므로 결과가 제한적입니다. 실제 내용 해석은 검토한 발췌문을 보내는 "증거 본문 발췌 분석"에서만 이루어집니다.
- MCP 경로의 `ai.request.execute`는 데스크톱과 달리 사건 AI 데이터 정책의 전송 평가를 거치지 않고 비밀 필드만 가린 요청을 보냅니다. 외부 제공자와 MCP를 함께 쓸 때 주의하세요. 후속 개선 대상입니다.
- 키워드 추천은 구조 정보만으로는 후보가 0건일 수 있습니다.
- 실제 증거·대용량 이미지·각 OS의 설치 후 전체 시나리오를 수동 검증한 정식판은 아닙니다. 백엔드 서비스·MCP 서버는 설치 파일에 포함되지 않으며 별도 실행이 필요합니다.
- 웹 번들의 500 kB 경고가 남아 있으며 코드 분할은 후속 개선 대상입니다.
