# APEX 0.1.0 Preview

APEX의 첫 Windows·macOS 데스크톱 프리릴리즈입니다. Electron 화면과 로컬 Python 분석 엔진을 함께 포함합니다.

## 다운로드

| 환경 | 설치 파일 | 별도 압축 파일 |
| --- | --- | --- |
| Windows x64 | `APEX-0.1.0-Windows-x64.exe` | — |
| macOS Apple Silicon (M 시리즈) | `APEX-0.1.0-macOS-arm64.dmg` | `APEX-0.1.0-macOS-arm64.zip` |
| macOS Intel | `APEX-0.1.0-macOS-x64.dmg` | `APEX-0.1.0-macOS-x64.zip` |

Windows에서는 설치 프로그램을 실행하고 설치 위치를 선택합니다. macOS에서는 해당 CPU용 DMG를 열고 APEX를 Applications 폴더로 복사합니다. 별도 Python·Node.js 설치는 필요하지 않습니다.

**이 빌드는 배포 인증서로 서명하거나 Apple 공증을 받지 않았습니다.** Windows SmartScreen이나 macOS Gatekeeper에서 확인 또는 실행 제한이 나타날 수 있습니다. 정식 서명 배포 전의 프리뷰이며, 조직의 실행 정책을 따라 주세요.

## 포함된 기능과 수정

- 사건·증거 등록, 파일 탐색, 검색, 타임라인, 아티팩트 조회, 보고서 작업을 제공하는 로컬 워크벤치
- APEX 로고, 단순한 다크 테마, Astryx 기반 조작 아이콘과 Material 파일 아이콘
- 이미지 미리보기, RGB/RGBA 채널·비트 플레인 확인, 비트 추출 결과와 조건·출처를 JSON으로 저장
- ZIP 증거 입력 안내, PNG 메타데이터, 검색 순위·원본 잘림 표시, 한국어 보고서 상태 개선
- 패키지 확인 스크립트의 로컬 HTTP 연결 제한 및 CI Bandit B310 실패 수정

## 알려진 제한

- 프런트엔드 인수인계 전체 기능과 모든 실제 증거·대용량 시나리오 검증이 완료된 정식판은 아닙니다. [가이드 준수 검토](https://github.com/APEX-digtal-forensic-tool/APEX_Digtal_Forensic_Tool/blob/401cc5ba4ac75506e9c50db16f3fa6a19a3fa648/docs/desktop/GUIDE_COMPLIANCE_REVIEW.md)를 참고하세요.
- 고급 검색 UI, 키워드 세트, 시간대 후보 확인, 일부 복구·OCR/STT·AI 연동은 미구현 또는 별도 의존성·설정이 필요합니다.
- 이미지 분석은 현재 논리 파일의 첫 프레임과 RGB/RGBA 8비트 변환을 기준으로 합니다. 디스크 이미지 내부 파일·다중 프레임·전체 이미지 포맷을 지원한다고 보장하지 않습니다.
- 자동 업데이트는 제공하지 않습니다. 새 버전은 GitHub Releases에서 직접 설치합니다.
- 기존 변경에 대한 실제 앱 전수 재검증은 수행하지 않았습니다. 이번 배포를 위해 로컬 테스트를 추가 실행하지 않았으며, 위 원격 CI 결과를 기준으로 게시합니다.
